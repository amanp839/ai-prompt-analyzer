# 🤖 AI Prompt Analyzer

A beginner-friendly Python tool that analyzes the quality of an AI prompt and provides suggestions for improvement.

## 🎯 Features

- Analyzes prompt clarity
- Checks for context
- Checks prompt specificity
- Checks output instructions
- Calculates a prompt quality score
- Provides suggestions for improvement

## 🛠️ Technologies

- Python
- Prompt Engineering
- Artificial Intelligence Concepts

## 🚀 How It Works

1. Run the Python program.
2. Enter an AI prompt.
3. The analyzer evaluates the prompt.
4. A quality score is generated.
5. The program provides suggestions for improving the prompt.
